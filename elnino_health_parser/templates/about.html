About the Project

Problem

Maharashtra Public Health Department publishes disease surveillance bulletins regularly. Extracting disease names, affected districts, case counts and dates manually is time-consuming and error-prone. No dedicated system focused on Maharashtra automatically extracts El Niño-related disease information into an interactive dashboard.

Solution

A Python / Flask web application that accepts PDF or text bulletins, extracts structured records using spaCy NLP + regular expressions, stores them in SQLite, and presents interactive charts and filterable tables for rapid outbreak monitoring.

Target Diseases

  • Dengue
  • Malaria
  • Chikungunya
  • Cholera
  • Leptospirosis
  • Heat Stroke

Tech Stack

  • Python 3 · Flask · SQLAlchemy · SQLite
  • spaCy · Regex · pdfplumber · Pandas
  • Plotly · HTML5 · CSS3 · Vanilla JS
